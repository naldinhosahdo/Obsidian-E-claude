# Sistema de Freios

Desacelera e para o veículo, convertendo energia cinética em calor (ou energia elétrica no freio regenerativo).

---

## Freio a Ar (veículos pesados)

| Componente | Função |
|---|---|
| **Compressor de ar** | Gera ar comprimido para o sistema |
| **Secador / Filtro de ar** | Remove umidade e impurezas |
| **Reservatório eixo 1** | Armazena ar para o eixo dianteiro |
| **Reservatório eixo 2** | Armazena ar para o eixo traseiro |
| **Reservatório de emergência** | Garante frenagem mínima em caso de falha |
| **Válvula de comando (pedal)** | Aciona o sistema |
| **Válvula de controle / distribuidora** | Distribui pressão de ar |
| **Válvula reguladora do compressor** | Controla pressão máxima |
| **Válvula de alívio** | Libera excesso de pressão |
| **Cilindro / Câmara de freio** | Converte pressão de ar em força mecânica |
| **Mangueiras e tubos de ar** | Conduzem o ar comprimido |

---

## Freio Hidráulico a Tambor

| Componente | Função |
|---|---|
| **Cilindro mestre** | Gera pressão hidráulica ao pisar no pedal |
| **Fluido de freio** | Transmite a pressão |
| **Linha de freio** | Tubulações e mangueiras |
| **Cilindro de roda** | Converte pressão hidráulica em força nas sapatas |
| **Sapatas** | Suporte das lonas de fricção |
| **Lonas** | Material de atrito que pressiona o tambor |
| **Tambor** | Superfície cilíndrica que gira com a roda |
| **Molas de retorno** | Afastam as sapatas quando o pedal é solto |
| **Ajustador** | Compensa o desgaste das lonas |

---

## Freio Hidráulico a Disco

| Componente | Função |
|---|---|
| **Cilindro mestre** | Gera pressão hidráulica |
| **Fluido de freio** | Transmite a pressão |
| **Linha de freio** | Tubulações e mangueiras |
| **Pinça** | Aperta a pastilha contra o disco |
| **Pistões** | Dentro da pinça, empurram a pastilha |
| **Pastilha** | Material de atrito |
| **Disco** | Superfície metálica que gira com a roda |

---

## Freio Regenerativo

Usado em veículos **elétricos e híbridos**. O motor elétrico age como gerador durante a frenagem, convertendo energia cinética em energia elétrica para recarregar a bateria.
